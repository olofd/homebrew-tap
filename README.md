# Homebrew tap

Casks for [Agneta](https://github.com/olofd/agneta), the macOS menu bar ACP gateway.

```bash
brew install olofd/tap/agneta
```

Agneta updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`. Casks here are written by Agneta's release workflow when a release is published; don't edit them by hand.
